Requires local Neo4j (`bolt://localhost:7687`) and Qdrant (`localhost:6333`). Install via `pip install -r requirements.txt` then `python -m spacy download en_core_web_sm`. Run the MCP server with `python mcp_graph_rag.py --transport streamable-http --path /mcp` (default host/port 127.0.0.1:8789). Ingest with `python graphrag_ingest_langextract.py --folder <dir> --entity-provider gliner|langextract ...`. Reset stores with `python 0_reset_all.py`. Indexes are created by `6_setup_indexes.py` or automatically on first use.
