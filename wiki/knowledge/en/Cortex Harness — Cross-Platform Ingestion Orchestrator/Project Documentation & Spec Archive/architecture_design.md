Flat documentation tree with three logical zones: `specs/` holds human-authored feature/design specifications (MCP CLI, COBOL analyzer, harness CLI, sync-code/doc, one-click install); top-level `.md` files are cross-cutting reference guides (`DATABASE_INTEGRATION.md`, `HARNESS_WORKFLOW.md`, `MCP_CAPABILITY_ACCEPTANCE_MATRIX.md`); `logs/` is a chronological changelog directory where each file follows a `YYYY-MM-DD-title.md` naming convention and is indexed by `logs/README.md`. There is no build step or runtime — consumers read these as plain Markdown; `specs/CLAUDE.md` is an auto-maintained Claude memory context marker rather than executable content.
