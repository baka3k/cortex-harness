`make install` (or `python scripts/mcp-lifecycle.py install`) creates `.venv`, installs root + `code-tiny` + `doc-tiny` requirements, then drops a user-local `~/.local/bin/dev` wrapper that re-invokes `cortex_harness/dev.py` through the venv Python. `make infra-up` pulls and runs `cortex-qdrant` (port 6333) and `cortex-falkordb` (port 6379) with `--restart unless-stopped`. `make start` opens separate terminal windows per MCP server and persists their PIDs under `.cache/mcp/`.
