Pure Python 3 + standard library (`subprocess`, `socket`, `urllib.request`, `signal`, `pathlib`); no third-party dependencies at script level. Windows path uses native PowerShell with `Invoke-WebRequest`, `Get-CimInstance Win32_Process`, and `Start-Process -EncodedCommand`; POSIX path relies on `ps -axo` and platform terminal launchers (`osascript`, `gnome-terminal`, `xterm`). Docker is invoked as an external CLI for Qdrant (`qdrant/qdrant`) and FalkorDB (`falkordb/falkordb`) containers.
