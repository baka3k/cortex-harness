Run from `code-tiny/`: create a venv, `pip install -r requirements.txt`, start FalkorDB/Neo4j and Qdrant externally, then either invoke an analyzer directly (`python -m tools.<lang>.<lang>_analyzer --graph-provider falkordb ...`) or start the MCP server with `python mcp/unified_mcp.py --transport streamable-http --host 127.0.0.1 --port 8788 --path /mcp`. The preferred orchestrator path is `dev init <project>` followed by `dev sync code --project-dir <project> [--full-scan|--change-detection hash --reconcile]`.
