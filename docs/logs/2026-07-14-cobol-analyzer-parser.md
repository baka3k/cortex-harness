# COBOL Analyzer Parser Implementation — 2026-07-14

## Context

The COBOL analyzer plan called for `.cbl`, `.cob`, `.cpy`, and `.copy` files to become first-class inputs to `dev sync code`, with parsing, copybook and symbol resolution, control-flow semantics, graph ingestion, incremental invalidation, vector indexing, and unified MCP discovery (`plans/260714-1702-cobol-analyzer-parser/plan.md:21`, `plans/260714-1702-cobol-analyzer-parser/plan.md:28`). Commit `8f23559b799c83c085f492dabed2570e8878e3bd` implements that contract as an integrated language analyzer rather than a separate service.

## Change

The parser discovers all four owned extensions, preserves source-format, dialect, encoding, original byte offsets, and syntax diagnostics, and extracts structure, data declarations, calls, `PERFORM`, `GO TO`, `ALTER`, file I/O, SQL, and CICS evidence (`code-tiny/tools/cobol/parser.py:22`, `code-tiny/tools/cobol/parser.py:139`, `code-tiny/tools/cobol/parser.py:187`, `code-tiny/tools/cobol/parser.py:246`).

Copybooks are selected by configured extension precedence, nested include closures are computed with missing/ambiguous/cyclic diagnostics, and reverse dependency traversal identifies transitive consumers of changed or deleted copybooks (`code-tiny/tools/cobol/resolver.py:44`, `code-tiny/tools/cobol/resolver.py:76`, `code-tiny/tools/cobol/resolver.py:152`). ## Impact

Risk level: **medium**. Projects can now analyze COBOL sources through the standard sync and query surfaces, including copybook fan-out, project-scoped graph traversal, and semantic vector search. The behavioral surface is broad, but deterministic IDs, original-source evidence, bounded confidence for dynamic control flow, path/target validation, staged mutation, and focused regression fixtures constrain false resolution and partial-write risk. The committed validation passed 21 COBOL tests plus the affected shared regression selection (`plans/260714-1702-cobol-analyzer-parser/reports/validation-report.md:14`). Live Neo4j/FalkorDB logical parity remains environment-gated; provider-neutral writer behavior is covered, but live parity was not exercised (`plans/260714-1702-cobol-analyzer-parser/reports/validation-report.md:32`).

## Decision

Keep COBOL within the existing primary-analyzer, `LanguageCodeWriter`, project collection, and unified-MCP architecture. Isolate grammar loading behind a preflighted runtime adapter, preserve uncertainty as diagnostics and confidence metadata, and resolve only provable static targets. For incremental safety, compute copybook reverse dependencies from both the old and new indexes and delay tombstones/cache advancement until staged analysis and writes succeed. This avoids a COBOL-specific service or backend, fabricated dynamic targets, and graph mutation from a partially analyzed project (`code-tiny/tools/cobol/cobol_analyzer.py:182`, `code-tiny/tools/cobol/pipeline.py:121`, `code-tiny/tools/cobol/semantics.py:195`).
